Codex

Register once · Install locally

Add the JEStats marketplace once, then install the plugin with the Codex CLI.

  1. Copy the two setup commands.
  2. Run them in your terminal with Codex installed.
  3. Start a local session and check the connection.
codex plugin marketplace add jestatsio/screamingfrog-plugin
codex plugin add jestats-screamingfrog-audit@jestats-plugins

Open Codex install details ↗

The app link requires the marketplace to be registered first. It opens install details for review. Node.js 20+ required.

Claude Code

One command · Review · Install

Paste the install command into a Claude Code session. Review the plugin and choose your scope.

  1. Copy the command below.
  2. Paste it in an interactive Claude Code session.
  3. Confirm the marketplace and choose an install scope.
/plugin install jestats-screamingfrog-audit --marketplace jestatsio/screamingfrog-plugin

One-command flow requires Claude Code 2.1.275+. Node.js 20+ required for the audit server.

Prefer terminal setup? 
claude plugin marketplace add jestatsio/screamingfrog-plugin
claude plugin install jestats-screamingfrog-audit@jestats-plugins

The archive installer requires Claude Code 2.1.224+. Official plugin installation guide ↗

Before your first audit

Have Screaming Frog ready.

Your licence stays in Screaming Frog. There is no JEStats account to connect.

Open the licensed desktop app

Use a Screaming Frog SEO Spider installation with native MCP support and database storage mode. Keep the application running and visible while the assistant works.

Enable its native MCP server

Choose File → Settings → MCP Server. The usual URL is http://127.0.0.1:11435/mcp. See Screaming Frog’s setup guide ↗ or our connection instructions.
